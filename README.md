# Bank Management System – Part 1 | C++

A simple Bank Management System developed using C++ as part of my programming learning journey.

## Features

- **Show Clients:** Display all clients.
- **Add New Client:** Add a new client.
- **Delete Client:** Delete an existing client.
- **Update Client:** Update client information.
- **Find Client:** Search for a client using their account number.

## Concepts Used

- Structures (`struct`)
- Enumerations (`enum`)
- Functions
- Vectors (`vector`)
- File Handling (`fstream`)
- Input / Output Operations
